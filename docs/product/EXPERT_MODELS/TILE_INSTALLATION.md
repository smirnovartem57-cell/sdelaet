# Expert Model — TILE_INSTALLATION

Status: TESTING  
Profile: `tile-installation` v1.0

## Назначение
Сравнивать предложения плиточников по одинаковому составу работ, а не по рекламной цене за м².

## Основные сценарии
- ванная / санузел / душевая;
- плитка или керамогранит на пол;
- облицовка стен;
- кухонный фартук;
- крупноформат и мозаика;
- сложная раскладка.

## Минимальный Intake
1. Зона работ.
2. Формат плитки.
3. Раскладка.
4. Примерная площадь.
5. Фото основания — предпочтительно.

## Что обязан раскрыть исполнитель
- итоговую стоимость и единицу расчёта;
- тип / формат плитки и раскладку;
- подготовку / выравнивание основания;
- гидроизоляцию мокрых зон;
- клей / расходники, если включены;
- подрезки, отверстия, ниши и короба;
- запил 45° отдельной строкой, если нужен;
- тип затирки;
- демонтаж, если требуется;
- исключения, доплаты, срок и гарантию.

## Нормализация
Предложения сравнимы только при одинаковом формате и типе раскладки и при раскрытом состоянии основания. В мокрых зонах без подтверждённой гидроизоляции предложение считается неполным.

## Red flags
- цена только «за м²» без подготовки основания;
- мокрая зона без гидроизоляции;
- крупноформат считается как обычная плитка без оговорок;
- эпоксидная затирка, запил 45°, отверстия или сложная раскладка появляются как доплаты после начала работ;
- цена `от` без фиксированного объёма.
