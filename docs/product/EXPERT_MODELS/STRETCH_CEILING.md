# Expert Model — STRETCH_CEILING

Status: TESTING  
Profile: `stretch-ceiling` v1.0  
Domain: `CONSTRUCTION / HOME_REPAIR / CEILING`

## JTBD
Пользователь хочет получить натяжной потолок с понятной полной стоимостью, где базовое полотно не маскирует доплаты за профиль, свет, карнизы, обходы труб и демонтаж.

## Сценарии
- стандартный натяжной потолок;
- теневой / парящий профиль;
- световые линии;
- скрытый карниз;
- потолок с точечными светильниками / люстрами;
- демонтаж существующего натяжного потолка.

## Минимальный Intake
1. Площадь или помещение.
2. Тип потолка / профиля.
3. Количество светильников / люстр.
4. Нужен ли скрытый карниз.
5. Фото помещения предпочтительно.

## Что обязан раскрыть исполнитель
- итоговую стоимость;
- площадь и материал полотна;
- тип профиля;
- светильники, люстры и закладные;
- скрытый карниз / ниши;
- обходы труб и другие сложные узлы;
- демонтаж, если требуется;
- исключения, доплаты, срок и гарантию.

## Нормализация
Предложения сравнимы только при одинаковой площади и сопоставимой конфигурации: полотно + профиль + свет + карниз + обходы + демонтаж.

Цена за м² без комплектации не считается подтверждённой полной стоимостью.

## Site inspection
На замере определяются точная площадь и периметр, геометрия, состояние стен для крепления профиля, скрытые коммуникации, обходы труб и фактические закладные.

## Red flags
- теневой / парящий потолок сравнивают с базовым профилем;
- светильники или закладные не включены в цену;
- скрытый карниз появляется доплатой после замера;
- цена «от» за м² выдаётся за итоговую;
- сложные световые решения предлагаются без спецификации комплектующих.
