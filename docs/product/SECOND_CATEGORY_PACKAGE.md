# SECOND_CATEGORY_PACKAGE

Status: ACTIVE  
Started: 2026-09-13

## Goal
Expand the Home / Repair launch set only with services where technical scope, hidden work and quote normalization materially improve contractor selection.

## Package order
1. `TILE_INSTALLATION` — плитка / керамогранит — TESTING.
2. `FLOORING_INSTALLATION` — ламинат / SPC / линолеум / паркетная доска — TESTING.
3. `WALL_FINISHING` — подготовка стен / покраска / обои — NEXT.
4. `INTERIOR_DOORS` — установка / замена межкомнатных дверей — PLANNED.
5. `STRETCH_CEILING` — натяжные потолки — PLANNED.

## Why these categories
All five have mass contractor supply and structurally different quotes. Headline unit prices hide preparation, demolition, consumables, geometry, additional cuts/edges, delivery or auxiliary works.

## Lifecycle
Every category follows the same gate: `RESEARCH → EXPERT_MODEL → TESTING → READY`. Manual user-facing review remains deferred until the package reaches the technical-audit milestone.
